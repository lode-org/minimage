* C ABI (=minimage_*=)

Function symbols use the =minimage_= prefix. Every buffer is
caller-owned. Coordinates, lattice vectors, and origins share one
consistent length unit; =minimage_cell_from_con_box= takes angles in
degrees. Displacements compute =wrap(q - p)=.

Every =int=-returning function returns =0= on success and =1= on failure
(null pointer, invalid cell, buffer/index mismatch, or overflow). Read
=minimage_last_error()= on the same thread immediately after a nonzero
return; do not free the returned pointer. The next successful
=minimage_*= call on that thread clears the slot so
=minimage_last_error()= returns =NULL=. =minimage_version()= returns a
process-static string and neither reads nor modifies the error slot.

Function symbols use =minimage_=, the full crate name, to avoid
mimalloc's =mi_= namespace. The non-default =capi-compat-names= Cargo
feature exports deprecated thin =mi_= aliases for migration and must
not be linked with mimalloc.

A slab rounds its in-plane coordinates and tries the nine neighbouring
images on a Lagrange-reduced basis of its two vectors; a wire rounds
along its one. The component normal to the periodic vectors is kept. A
half-box tie keeps the engine wrap =s - floor(s + 1/2)=, as
=Cell::displacement_euclidean= does. With all three axes periodic a
=PartialCell= is a =Cell= and returns its displacement bit for bit.

=wrap_ortho_half_strict(delta, length)= (Rust) and
=minimage::wrap_ortho_half_strict(delta, length)= (C++) give identical
results. The result is =delta - n * length= for an integer
=n=, folded from the exact remainder =fmod(delta, length)= into the
closed interval =[-length/2, length/2]=, so it is finite and in range for
any finite =delta= and finite positive =length=, including large
multiples such as =1e308= against =0.5=. When the remainder equals
=length/2= exactly in binary the result keeps the sign of =delta=:
=15= and =-15= against =10= give =5= and =-5=. A decimal tie such as
=0.45= against =0.3= is not a binary tie and returns its nearest image,
=-0.14999999999999997=. A non-finite =delta=, or a =length= that is not
finite or not strictly positive, returns NaN; Rust does not panic and
the C++ function stays =noexcept=.

=MINIMAGE_SIMD= overrides the SIMD path choice. An unknown name is
ignored. A name this CPU cannot run selects =scalar=. The selection is
cached. Details are on [[file:simd.org][SIMD paths and dispatch]].

* Python

Exported module items: =Cell=, =PeriodicSpace=,
=reduce_image_pairs=, and =__version__=.
Array arguments accept any host CPU DLPack producer, read in place when
contiguous and aligned; array results return a NumPy array (or a list
when NumPy is absent). Invalid inputs raise =ValueError=, =TypeError=,
or =BufferError=.

| =dist2(p, q)=, =displacement(p, q)=, =wrap(diff)= | Single-pair engine wrap |
