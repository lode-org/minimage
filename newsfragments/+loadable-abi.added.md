A C interface for hosts that load the library at run time, beside the
existing entry points, which keep their names and behaviour. A host resolves
`minimage_abi_stamp`, `minimage_abi_compatible`, and `minimage_ops_get` by
name; compatible means the same `MINIMAGE_ABI_MAJOR` and
`MINIMAGE_ABI_LAYOUT_REVISION`, and the minor is informational. The
size-prefixed `minimage_ops` table holds lattice handles built from edges or
vectors with per-axis periodicity, the engine wrap and the nearest image of
many differences or pairs, and the wrap of many points into the cell. Each
returns an `int32_t` status with a stable code: `0` success, positive for a
recoverable failure such as `MINIMAGE_STATUS_BAD_CELL` or
`MINIMAGE_STATUS_UNSUPPORTED`, negative for misuse or a panic caught at the
boundary. `minimage_capabilities` reports what the library does, and a
missing capability is `MINIMAGE_STATUS_UNSUPPORTED`, never a different
result. `include/minimage_abi.hpp` is a header-only C++ wrapper over the
table, Meson provides the headers alone as `minimage-headers`, and
`packaging/wrapdb/minimage-headers.wrap` serves a host with no Rust
toolchain.
