# minimage branding

Original mark for **minimage** (minimum-image convention on a
periodic parallelepiped), in the same LODE indigo / amber family as
linkcell and readcon-core.

## Concept

- **Sheared parallelogram** — the cell is a general parallelepiped H,
  not an orthogonal dump box.
- **Dashed raw vector** — the Cartesian pair across the long way.
- **Gold wrap** — the fractional minimum image, the short path that
  crosses a periodic face.
- **Pale source, amber image** — the two points of one pair.
- **Palette** — indigo / violet LODE-science (`#1E1B4B`, `#312E81`,
  `#4F46E5`) + amber (`#FBBF24`).
